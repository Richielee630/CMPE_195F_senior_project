# Design direction

Crypto Solution: “A world of crypto. Made clear.”

The renewal uses Apple-inspired restraint without Apple branding: a warm off-white canvas, white cards, system sans-serif type, a large two-tone headline, subtle blue accents, and soft depth. Market data leads; personal tools sit one click away. The pearlescent sphere is a visual motif rather than a data visualization.

Responsive layouts adapt navigation, cards, tables, dialogs, and portfolio forms. Dialogs use native browser focus containment and Escape handling. Interactive controls have accessible labels, focus rings, and reduced-motion behavior. Canvas charts have descriptive labels; current numeric data is displayed in text alongside them.
